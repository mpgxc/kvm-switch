# Ícones dos destinos

PNGs de 128 px do [Noto Emoji](https://github.com/googlefonts/noto-emoji) (`2D/png/128`), sob a licença Apache 2.0. O nome de cada arquivo é o código Unicode do emoji.

| Arquivo | Emoji |
|---|---|
| `1f5a5.png` | 🖥 |
| `1f4bb.png` | 💻 |
| `1f34e.png` | 🍎 |
| `1f427.png` | 🐧 |
| `1fa9f.png` | 🪟 |
| `1f3ae.png` | 🎮 |

São usados no Linux, onde o GPUI desenha parte desses emojis sem cor. Para oferecer outro ícone, acrescente o PNG aqui, o emoji em `ICONS` (`src/ui/settings.rs`) e a linha dele em `src/ui.rs`.
